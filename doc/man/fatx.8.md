# NAME

fatx - complete set of commands to manage Xbox 360 FATX filesystem

# DESCRIPTION

**fatx** includes the following commands. Please take a look at each manpage:

- **mkfs.fatx** creates a FATX filesystem.
- **label.fatx** prints or changes the name of a FATX filesystem.
- **fsck.fatx** checks the FATX filesystem.
- **unrm.fatx** tries to recover deleted files on a FATX filesystem.
- **fusefatx** mounts a FATX filesystem.
