# Quick Start After Checkout

## To Resume Development on Another Machine

### 1. Clone and Setup
```bash
# Clone the repository
git clone <repo-url> fatx
cd fatx

# Read the current session state
cat SESSION_PROGRESS.md
```

### 2. Build
```bash
# Configure CMake
cmake -B build -DCMAKE_BUILD_TYPE=Debug -DCMAKE_EXPORT_COMPILE_COMMANDS=ON

# Build all targets
cmake --build build --config Debug -j 4
```

### 3. Run Tests to Verify Status
```bash
# Run all tests (should show 21/21 passing)
./build/fatx_tests

# Run with verbose output
./build/fatx_tests -v

# Run specific test suite
./build/fatx_tests --gtest_filter="DeviceDirectTest*"
```
